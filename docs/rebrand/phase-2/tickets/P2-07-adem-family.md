# P2-07 — Design Adem and Adem Pro Marks

Status: complete
Blocked by: P2-01

## Objective

Create subordinate, related marks for the first-party Adem and Adem Pro models.

## Deliverables

- `branding/maktabi/source/adem-model-mark.svg`.
- `branding/maktabi/source/adem-pro-model-mark.svg`.
- Model-list proof on dark and light UI surfaces.

## Completion evidence

Approved 2026-09-27. Adem uses a converging module-derived A; Adem Pro reuses that base with one external bracket modifier. Thinking levels remain text and OmniRoute has no customer-facing mark.

## Rules

- Derive an `A` from the Maktabi module and corner system.
- Adem Pro reuses the Adem base mark and adds one restrained modifier.
- Obsidian/White only; thinking levels remain text.
- OmniRoute receives no customer-facing mark.

## Acceptance

- Adem and Adem Pro are related but distinguishable at 24 px.
- Neither mark competes with or replaces the Maktabi application identity.
- No provider or upstream Z.ai visual language remains.
