# Generated Maktabi assets

This folder contains generated derivatives and runtime-ready exports. Keep editable identity masters, proofs, and source concepts under `branding/maktabi/source/`; do not edit generated artwork in place when a source master should change.

- `app/` — startup, first-run, model connection, ready, empty-state, and banner artwork.
- `windows/` — Windows PNG/ICO export matrix.
- `web/` — favicon and web icon exports.
- `macos/` and `future-ios/` — reserved routes for later platform exports.
- `social/` — reserved routes for approved social derivatives.
